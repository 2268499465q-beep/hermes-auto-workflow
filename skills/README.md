# Skills 目录说明

这里保存四个经过通用化重写的 AI Skills。每个 Skill 文件夹只保留运行所需的 `SKILL.md`，用户说明集中放在本页。

| Skill | 职责 |
|---|---|
| `cognitive-awakening` | 在任务开始前确认目标、输入、边界和完成证据 |
| `execution-guard` | 在执行过程中设置检查点，控制错误扩散和外部写入 |
| `task-breakdown` | 把目标拆成依赖清楚、可以验收的小步骤 |
| `notion-bridge` | 生成复盘内容并安全地写入 Notion |

这些版本不包含原始个人画像、专业背景、求职目标、公司信息或第三方方法论内容。

安装时可按 Agent 平台要求复制单个 Skill 文件夹。公开仓库只提供示例，不会自动写入本机 Hermes Skill 目录。
