# Task Preflight

在执行前完成一次简短预检。只收集会改变方案或结果的信息，不把预检变成长对话。

## 检查顺序

1. 用一句话重述最终交付物。
2. 列出已经具备的输入和仍缺少的关键输入。
3. 识别权限、隐私、时间、格式和外部写入限制。
4. 定义可以观察的完成证据。
5. 选择一个能在当前回合完成的首个动作。

## 何时直接开始

满足以下条件时直接执行：

- 交付物明确。
- 输入足以支持第一步。
- 不需要新增授权。
- 操作可逆或只读。

## 何时暂停

只有在缺失信息会明显改变结果，或下一步需要新的外部权限时暂停。提出一个最小问题，说明该答案会影响什么。

## 输出要求

- 先说明当前准备执行的结果。
- 不输出内部评分或冗长自我分析。
- 不编造用户经历、系统状态或已完成的验证。
- 对暂时无法验证的事实标明边界。
