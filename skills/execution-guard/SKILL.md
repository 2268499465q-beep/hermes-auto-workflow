# Execution Guard

把执行过程控制在可观察、可停止和可恢复的范围内。

## 开始前

1. 标记只读动作和写入动作。
2. 确认写入目标、权限和回滚方式。
3. 为凭据、个人数据和日志设置禁止输出项。
4. 记录预期成功信号和失败信号。

## 执行中

对每个步骤执行以下循环：

1. 检查输入是否存在且格式正确。
2. 只运行当前步骤需要的最小操作。
3. 检查退出码、状态码或生成文件。
4. 失败时停止后续写入，保留不含敏感值的错误摘要。
5. 成功后再进入下一步。

## 外部写入

- 默认先使用预览、草稿或 dry-run。
- 发送、发布、删除和覆盖前重新确认授权范围。
- 不把读取权限自动解释为写入权限。
- 不在错误日志中打印 Authorization、cookie、token 或完整私人内容。

## 验收

完成后至少检查：

- 交付物存在且可打开。
- 关键命令能够运行。
- 示例和真实数据已分离。
- 敏感信息扫描没有命中。
- 未授权的外部状态没有变化。
