# 常见故障与处理

## 1. 交互式终端能运行，定时任务找不到命令

调度器的 PATH 往往不同。设置 `DIDA_CLI_PATH` 为 CLI 的完整路径，并在任务配置中使用明确的 Python 路径和工作目录。

## 2. 已完成任务数量明显偏多

按日期查询的接口可能返回跨日数据。脚本会再次解析 `completedTime`，按开始和结束时间过滤，并用任务 ID 去重。检查时区偏移和结束日期是否符合预期。

## 3. Notion 返回 401 或 403

401 通常表示 token 无效或没有进入当前进程。403 常见于 Integration 没有被添加到目标页面。检查环境变量是否存在，再检查页面共享权限。不要把 token 打印到终端排查。

## 4. Notion 创建成功但内容为空

先运行 `--dry-run` 检查 Markdown。若 Markdown 正常，确认 API 版本是否支持当前请求格式。必要时改用先创建空页面、再追加 blocks 的方式。

## 5. 代理或网络设置导致 API 超时

生产脚本不应硬编码本机代理。需要代理时，通过 `HTTPS_PROXY` 和 `NO_PROXY` 等标准环境变量配置。排查时只记录目标域名、状态码和耗时，不记录请求头。

## 安全排查顺序

1. 查看缺失变量名，不查看变量值。
2. 使用 `--dry-run` 重现。
3. 缩小到一个合成任务或测试页面。
4. 记录状态码和截断错误。
5. 问题解决后清理测试页面和临时输出。
